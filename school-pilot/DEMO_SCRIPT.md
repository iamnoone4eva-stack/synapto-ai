# Synapto — 15-minute school demo script

**Audience:** principal, ICT teacher, or club lead  
**Goal:** they open the product, complete one lesson, and agree a pilot date.

## Before you arrive
- [ ] Live URL works on school Wi‑Fi (or offline `synapto-complete.html` on a USB stick)
- [ ] One sample student profile ready
- [ ] Printed one-pager (`one-pager.html` → PDF)
- [ ] Parent consent template (below)

## Minute 0–2 — Hook
> “Students already use AI on their phones. Synapto teaches them *how it works* in short lessons — like a game, with real concepts.”

Show home screen: worlds, streak, trophies.

## Minute 2–7 — Live lesson
1. Continue as learner → pick age band matching their students  
2. Open **xAI & Grok** world *or* an age-appropriate intro world  
3. Complete **one** short lesson + quiz  
4. Show **Continue → next lesson** and the **trophy**  
5. Open **Spark** chat: ask “What is machine learning?”

## Minute 7–10 — Teacher angle
- Classroom code / parent mode (if relevant)  
- Under-18 guardian email  
- Certificates after a world  

## Minute 10–13 — Pilot ask
> “We’d like a 4–6 week pilot with one class, two lessons a week. Free for the pilot. We’ll train the teacher in 30 minutes and send a short report at the end.”

Confirm: class size & grade, lab vs phones, start week.

## Minute 13–15 — Leave-behind
- One-pager PDF  
- Demo link  
- Your phone number  
- “I’ll message you Thursday to confirm.”

## Parent consent (short template)

> We are running a short AI literacy pilot using the Synapto learning app. Students complete interactive lessons about how AI works. Progress is stored for learning only. Students under 18 should use a parent/guardian contact email. No payment is required for this pilot. Contact: ___________

## Objection handling
| They say | You say |
|----------|---------|
| No computers | Works on phones; shared devices OK |
| AI is dangerous | That’s why we teach literacy and safety |
| No time | 15–20 min lessons, twice a week |
| Cost | Pilot free; later school plan in ETB if useful |
